A web-based platform for seamless event organization and participation, built in 24 hours during [MECIA Hackathon].

🚀 Features : 
	•	Create and manage events.
	•	User authentication for organizers and attendees.
	•	Search and filter events by category, location, or date.
 	•	Real-time notifications.
	•	Responsive design for all devices.

 💡 Tech Stack :
Frontend: [React.js/HTML/CSS]
Backend: [Node.js/Express/Django]
Database: [MongoDB/MySQL]
